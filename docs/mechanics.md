# 입력과 파손 규칙

## 도구

| 도구 | 작동 | 남는 것 |
|---|---|---|
| 망치 | 클릭당 1회 충격 | 중심 구멍·분기 균열·날아가는 조각 |
| 전기톱 | 누른 채 경로 이동 | 실제 이동 경로를 연결하는 절단면 |
| 연발총 | 누르는 동안 약 0.075초마다 발사 | 산포가 있는 작은 탄흔·탄피 |
| 화염기 | 점화 후 자율적으로 5초가량 확장 | 점점 넓어지는 그을음·일시적인 불꽃 |
| 퇴근 도장 | 클릭당 1회 인쇄 | 조금씩 각도가 다른 붉은 승인 인쇄 |
| 흰개미 | 클릭당 6마리, 최대 72마리 | 13초 동안 돌아다니는 개체와 영구적인 갉은 흔적 |

파손은 immutable mark 목록으로 남고, 화면에 새로 생긴 mark만 추가로 그립니다. 실행 취소나 복구에서는 손상 캔버스를 지우고 필요한 기록만 다시 그립니다. 창이나 도구 UI를 이미지 한 장으로 합치지 않습니다.

## 도전 3단계

1. 오류 창 강제 수리, 45초: 망치로 서로 다른 표적 3개를 맞히고 전기톱으로 250px를 자릅니다.
2. 퇴근 서류 처리, 55초: 표적 3개에 도장을 찍고 화면 3%를 태웁니다.
3. 야근 버그 퇴치, 65초: 흰개미 갉기 45회, 연발총 25발, 화면 파손율 8%를 달성합니다.

같은 표적 반복 타격은 다른 표적을 처리한 것으로 세지 않습니다. 다른 도구로 맞힌 표적도 인정하지 않습니다. 단계 사이에는 별도 소개와 시작 버튼이 있으며, 제한 시간이 끝나면 실패하고 같은 단계에서 재도전할 수 있습니다.

파손율은 게임 내부의 10px 격자에서 측정하는 근사 면적입니다. 원화 알파의 정확한 픽셀 비율이 아닙니다. 그을음 면적은 별도 격자입니다.

## 입력·생명주기

포인터 down/move/up은 다음 고정 업데이트까지 큐에 남습니다. 클릭했다 떼는 두 이벤트가 한 프레임 안에 들어와도 순서대로 실행되어 타격이 사라지지 않습니다. Space도 동일한 큐를 사용합니다.

도구를 들고 있을 때 창 내용 클릭은 파손입니다. `0`을 누르면 파일 아이콘과 창 내용을 정상 조작합니다. 제목 표시줄 드래그·최소화·닫기·시작 메뉴·도구 팔레트는 파손 레이어와 분리되어 있습니다.

한 제스처 전의 스냅샷으로 최대 30동작을 취소합니다. 흰개미나 불을 만들었던 제스처를 취소하면 그 뒤 자율적으로 생긴 흔적도 함께 되돌립니다. 전체 복구는 현재 게임의 파손·벌레·불·도구 기록만 비웁니다. 도전 중 복구는 목표를 초기화하지만 시간을 추가하지 않습니다.

메모리 상한은 파손 mark 10,000개이며 도달하면 복구 안내를 표시합니다. 자유 모드에서 계속 사용하려면 전체 복구를 누릅니다. 정지·창 포커스 상실·다른 탭 전환에서는 입력을 해제하고 벌레·불·제한 시간을 함께 멈춥니다. 큰 프레임 간격은 최대 0.05초 업데이트로 제한합니다.
