## 확인한 다섯 가지

1. 메뉴는 큰 웹사이트 내비게이션이 아니라 회색의 작은 **2열이 아닌 3열 × 2행 도구 팔레트**입니다. 망치·톱·총·화염기·도장·흰개미 6종이 도구 그림과 함께 놓입니다.
2. 파손이 배경 사진 위에 계속 쌓입니다. 검은 구멍·붉은 작은 흔적·갈라짐·벌레가 동시에 남아, 한 개 효과가 끝날 때 화면 전체가 초기화되는 구조가 아닙니다.
3. 큰 망치 구멍과 작은 연발 탄흔의 크기·가장자리가 다릅니다. 흰개미는 도장 같은 정지 이미지가 아니라 작은 개체 여러 마리로 표현됩니다.
4. 파손 뒤에도 실제 데스크톱의 상단 메뉴와 하단 독이 보입니다. 게임 세계가 별도 전장으로 바뀌는 대신 바탕화면을 장난감처럼 다루는 느낌입니다.
5. 도구 메뉴 아래에는 오른쪽 마우스·청소·나가기 같은 짧은 키 안내가 있습니다. 조작 안내는 큰 튜토리얼 사이트가 아니라 작은 유틸리티 프로그램의 언어를 씁니다.

## Flamingo 98의 고유 화면

`unslop-ui`에 따라 참고·색·서체·레이아웃 목적을 먼저 명시했습니다. 공통 아케이드 포털이나 SaaS 카드 화면은 만들지 않았습니다.

- **색:** 청록 단색 바탕화면, 회색 3단 베벨, 짙은 남색 제목 표시줄. 1990년대 유틸리티 화면의 대비를 선택했습니다. 분홍은 플라밍고 엽서와 붉은 도장에만 씁니다.
- **글자:** 로컬 Galmuri11을 작게 사용합니다. 긴 소개 문구보다 창 제목·메뉴·상태 표시를 우선합니다.
- **구조:** 처음부터 실제 게임인 가상의 OS가 열립니다. 파일 창·메모·사진 보기·프롬프트·휴지통은 각자 열고 닫고 최소화할 수 있으며, 작업 표시줄에서 복원합니다.
- **도구:** 독립 3×2 팔레트가 파손 캔버스 위에 남습니다. 도구 그림과 커서 그림은 같은 새 Canvas 원화를 사용합니다.
- **파손:** 망치는 분기된 긴 균열과 비정형 구멍, 톱은 연결된 절단면과 들뜬 조각, 총은 작은 금속성 탄흔, 불은 커지는 그을음과 불꽃, 도장은 사각 승인 인쇄, 흰개미는 작은 신체와 자율 궤적을 갖습니다.

원작이 실제 데스크톱을 덮어 쓰는 프로그램처럼 보이는 점은 게임 안의 가상 OS로만 패러디했습니다. 실제 운영체제 화면을 읽거나 덮는 기능은 없습니다.
