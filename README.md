## 단독 실행

Node.js 22.12 이상이 필요합니다. 다른 게임 저장소나 공통 엔진 없이 실행됩니다.

```sh
npm ci
npm run dev
```

[가상 데스크톱 열기 · 127.0.0.1:4205](http://127.0.0.1:4205/)

4205가 사용 중이면 다른 포트로 자동 이동하지 않고 오류를 냅니다.

```sh
npm test
npm run build
npm run capture
```

## 조작

| 입력 | 동작 |
|---|---|
| 1–6 | 망치·전기톱·연발총·화염기·도장·흰개미 |
| 왼쪽 클릭 / 드래그 | 선택 도구 사용. 총·불은 누르고 있으면 연속 작동 |
| 방향키 + Space | 가상 커서 이동 + 도구 사용 |
| 0 | 창 내용·아이콘 조작 모드 |
| 창 제목 드래그 | 도구를 들고 있어도 창 이동 가능 |
| 창의 `_` / 작업 표시줄 | 최소화 / 다시 복원 |
| U / Ctrl+Z / Cmd+Z | 한 동작 취소, 최대 30동작 |
| P / Escape | 일시정지 |
| 오른쪽 클릭 | 도구 창 다시 열기 |

시작 메뉴 또는 화면 아래 **3단계 도전**에서 제한 시간 도전을 시작합니다. 일반 모드는 시간 제한이 없습니다. 소리는 기본 꺼짐이며 켜면 자체 합성 효과음만 재생합니다. 창 포커스를 잃거나 다른 탭으로 이동하면 불·벌레·제한 시간이 함께 멈춥니다.

## 실제 컴퓨터에 영향을 주지 않는 구조

- 화면 캡처·화면 공유·파일 시스템·클립보드 접근 API를 사용하지 않습니다.
- 부리 프롬프트는 `help`, `dir`, `ver`, `squawk`, `clear`에 미리 정한 글을 표시할 뿐, 명령을 실행하지 않습니다.
- 내 둥지·메모·사진·휴지통은 이 HTML에만 존재합니다. 복구와 휴지통 비우기도 이 가상 화면 안의 동작입니다.
- 원본 Desktop Destroyer 실행 파일이나 원작 그래픽·음원을 포함하지 않습니다.

## 검증

`npm test`는 6종 효과의 서로 다른 상태 변화, 유지·종료, 실행 취소, 전체 복구, 일시정지, 빠른 down/up 입력 보존, 잘못된 표적, 제한 시간 실패, **일반 도구 입력만 사용한 3단계 성공**을 검증합니다. 성공 테스트는 점수·목표·시간 값을 직접 바꾸지 않습니다.

27개 테스트와 빌드가 통과했습니다. 별도의 실제 브라우저 검수에서는 창 이동·최소화/복원, 도구 전환·복구·정지, 세 단계 도전 성공을 확인했습니다. CPU 검증과 `capture` 자체는 DOM 창 드래그나 실제 브라우저 클릭을 증명하지 않습니다. 작은 휴대전화에서는 글씨와 도구가 축소되며 실제 모바일 기기 검수는 완료하지 않았습니다.
